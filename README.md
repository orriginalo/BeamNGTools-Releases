# BeamNGTools releases

This repository hosts Windows builds of BeamNGTools. The application source code is maintained in a private repository.

Download a build from [Releases](https://github.com/orriginalo/BeamNGTools-Releases/releases). Versions marked **Pre-release** are for testing. The application checks this repository for updates and verifies each downloaded executable with a pinned Ed25519 public key before installing it.

The `.sig` file is used by the in-app updater; manual downloads only need `BeamNGTools.exe`.
